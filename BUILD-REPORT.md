# Деньги в порядке — сборка v1

## Результат
Создана отдельная копия проекта для перехода к локальному режиму. Исходная распаковка и исходный ZIP не изменялись.

## Выполненные изменения
- Удалён обязательный Firebase Auth gate на главной странице.
- Главная страница запускается без регистрации; отображается локальное имя из `dvp_user_name` либо «Участник».
- `auth.html` заменён экраном пояснения локального режима без сбора email/пароля.
- Профиль переведён на чтение прогресса из локального хранилища; выход заменён переходом на главную.
- Облачная синхронизация отключена.
- Удалены ссылки на отсутствующий `cloud-sync.js` и старые Firebase compat script tags.
- Сертификат больше не требует Firebase Auth; имя берётся из локального `cert_name` / `dvp_user_name`.
- Сброс прогресса больше не вызывает `localStorage.clear()`. Он удаляет перечисленные ключи и известные семейства ключей приложения, не затрагивая посторонние данные сайта.
- Исправлена синтаксическая ошибка экспорта Excel в `workbook5.html`.
- Добавлены `manifest.json`, SVG-иконки и Service Worker.
- Service Worker предварительно кэширует все 43 HTML-страницы и основные PWA-файлы; посещённые внешние GET-ресурсы кэшируются при доступе к сети.
- Добавлены `storage-inventory.json` и этот отчёт.

## Проверки
- HTML-страниц: 43.
- Inline JavaScript-блоков: 86.
- Синтаксические ошибки JavaScript после исправления: 0.
- Неразрешённые локальные ссылки `src` / `href`: 0.
- Ссылки на Firebase и `cloud-sync.js` в HTML: 0.
- Вызовов `localStorage.clear()` в HTML: 0.

## Что пока не реализовано / не подтверждено
- IndexedDB как основное хранилище.
- Шифрованный экспорт/импорт резервной копии.
- Полное локальное хранение CDN-библиотек и шрифтов.
- Реальное браузерное тестирование всех сценариев на Android, iOS и компьютере.
- Полная проверка восстановления после очистки кэша/переустановки браузера.
- Проверка всех финансовых форм, расчётов, графиков, сертификата и экспорта Excel в браузере.

## Важное ограничение офлайн-режима
Все локальные HTML-страницы предварительно добавлены в кэш Service Worker. Внешние библиотеки и шрифты остаются CDN-зависимостями: Service Worker может сохранить их после успешной загрузки, но на первом посещении без сети отдельные функции могут быть недоступны. Поэтому эту сборку нельзя считать окончательно подтверждённой для полностью автономной работы.
