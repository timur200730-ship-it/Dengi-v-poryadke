ДЕНЬГИ В ПОРЯДКЕ — СБОРКА v1 (ЛОКАЛЬНЫЙ РЕЖИМ)

Что это:
- Вход и регистрация не требуются.
- Финансовые данные остаются в хранилище браузера на текущем устройстве.
- Облачная синхронизация Firebase отключена.
- Добавлены PWA manifest и Service Worker с предварительным кэшированием всех HTML-страниц.

Как проверить:
1. Разместите содержимое архива на HTTPS-хостинге (например, GitHub Pages) либо запустите локальный сервер.
2. Откройте index.html онлайн один раз и дождитесь завершения загрузки.
3. Перейдите по нескольким страницам, проверьте формы и сохранение.
4. Перезагрузите страницу и проверьте сохранность данных.
5. Включите авиарежим и проверьте главную страницу и ранее посещённые разделы.
6. Не очищайте данные браузера, пока не сделали резервную копию.

Важно:
- Не открывайте HTML двойным щелчком через file://: Service Worker/PWA там не работают.
- Часть внешних библиотек и шрифтов пока загружается с CDN. Для надёжной работы без сети эти файлы ещё предстоит перенести в проект.
- В этой сборке пока нет шифрованного экспорта/импорта и миграции в IndexedDB.
- Не публикуйте сборку поверх действующего сайта до проверки на копии и отдельного согласования.
